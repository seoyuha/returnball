잠시 후 새 상대와 자동으로 경기해요

영어 리턴볼 게임하는 방법

영어로 답해서 반격을 준비하고, 원이 겹칠 때 공을 터치해 되받아쳐요!

  1. 경기 입장선생님이 알려 준 반 코드와 내 이름으로 들어가요. 선생님이 시작하면 상대가 자동으로 정해져요.
  2. 정답으로 반격 준비공이 내 쪽으로 오면 영어 질문이 떠요. 시간 게이지가 다 닳기 전에 알맞은 응답을 눌러요.
  3. 원이 겹칠 때 공을 터치!정답이면 선택지가 사라지고 공이 다가와요. 바깥 원이 줄어들어 안쪽 원에 겹칠 때 움직이는 공을 직접 눌러요.
  4. 점수 얻기오답, 시간 초과, 너무 빠르거나 늦은 터치는 상대 1점! 먼저 목표 점수를 얻으면 이겨요. PERFECT 반격은 상대 문제 시간을 1초 줄여요.

실수해도 괜찮아요. 다음 랠리에 바로 다시 참여해요. 경기가 끝나면 다른 친구와 자동으로 다시 경기해요.
