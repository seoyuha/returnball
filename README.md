# 영어 리턴볼 (English Return Ball)

6학년 영어 11단원(전통문화)·12단원(환경 보호) 1대1 대결 게임 + 선생님 관리 사이트.
블레이드볼처럼 공이 나에게 날아오는 동안 영어 질문에 알맞은 응답을 고르면 공이 상대에게 되돌아가요.

## 규칙
- 공이 오면 질문과 응답 3개가 떠요. 시간 게이지(=공이 도착하는 시간) 안에 정답을 누르면 반격!
- 랠리가 이어질수록 공이 빨라져요(기본 8초 → 한 번 받아칠 때마다 0.45초씩 줄어 최소 4초).
- 오답이나 시간 초과면 상대 1점. 먼저 5점이면 승리(설정에서 바꿀 수 있어요).
- 점수: 승리 10 · 무승부 6 · 패배 3 + 맞힌 문제 수.

## 주소
- 학생: `/`  (반 입장 코드 8반 0608 · 9반 0609 · 10반 0610)
- 선생님: `/teacher.html`  (비밀번호는 다른 게임과 같아요. Render 환경변수 `TEACHER_PASSWORD`로 바꿀 수 있어요)

## 선생님 관리
- 경기 현황: 단원 선택(11/12), 시작(자동 짝 배정)·잠시 멈춤·경기 끝내기, 진행 중인 경기 실시간 보기, 입장 코드 크게 띄우기
- 자동 배정: 끝난 학생은 8초 뒤 최근에 만나지 않은 친구와 다시 짝, 짝이 없으면 10초 뒤 AI와 대결(점수 반영)
- 기다리는 학생은 "AI 연습"을 할 수 있고(점수 미반영), 짝이 생기면 바로 진짜 경기로 넘어가요
- 랭킹: 우리 반 / 6학년 전체 / 반 대항전, 크게 띄우기, CSV 저장
- 오답 함께 보기: 많이 틀린 문제 순서, 크게 띄워 '정답 보기'
- 문제 관리: 켜고 끄기, 추가, CSV 올리기/내려받기 (단원,질문,정답,오답1,오답2,그림,그림설명,해설)
- 학생 관리: 학생별 기록, 내보내기, 반 기록 지우기

## 그래픽
- 학생 화면: `public/img/` (title_bg, logo, court11, court12, robot_blue, robot_red, ball — 같은 이름으로 바꾸면 자동 적용), 시작 버튼 `public/img/buttons/`
- 교사 화면: `public/img/teacher/` (틀·탭·버튼·단원 카드·상태 아이콘·표·크게 띄우기·배지·시상대·점수판), 스타일은 `public/teacher-skin.css`
- QR코드: `public/vendor/qrcode.min.js` (인터넷이 막혀도 동작, 라이선스 사본 함께 보관)

## 추가 기능
- 경기 크게 보기: 경기 카드를 누르면 칠판용 점수판(이름·점수·공 방향·랠리). 문제와 정답은 보이지 않아요.
- 수업 마무리: '경기 끝내기' 뒤 이번 수업(시작~끝)만 모아 1~3위, 최고 랠리, 가장 많이 틀린 문제를 보여 줘요. '지난 수업 마무리 보기'로 다시 열 수 있어요.
- 반 대항전 그래프: 랭킹 → 반 대항전 → 그래프 보기(평균 점수 / 정답률)
- 틀린 비율 배지: 0~29% 낮음 · 30~59% 보통 · 60~100% 높음, 기록이 없으면 '기록 없음'


## B안 · 경기장 이동형 (기본)
- 2~4명이 경기장을 움직이고, 황금 공이 한 명을 쫓아요. 문제를 맞히면 치기 충전(최대 3), 3연속 정답이면 슈퍼 치기.
- 틀리면 쉬는 시간: 2초 → 3.5초 → 5초(연속 오답일수록 길어짐). 점수 = 순위 점수 + 정답 2개당 1점 + 받아치기.
- 공이 오면 치기 범위 원 표시, 치기가 있으면 겨눈 친구에게 점선 화살표. 지연 보정(최근 0.26초 공 위치 + 맞기 직전 0.18초 유예).
- 하트를 다 잃으면 부활 도전(15초 안에 3문제 연속 정답, 경기당 1번). 실패하면 순위 확정 → 개인 결과 6초 → 먼저 탈락한 친구들끼리 새 경기.
- 2명 남으면 결승(자유 경기는 '마지막 대결') 연출과 공 가속, 랠리 8번 이상이면 피버 타임(받아치기 2배).
- 대회 방식(교사 화면): 자유 경기 / 토너먼트(경기마다 상위 2명 진출, 4명 이하면 결승, 탈락자는 자유 경기) / 리그전(1인 N경기, 승점 = 인원 − 등수).
- 시험: `FAST=1 PORT=3561 npm start` 후 `COMP=tournament N=6 node test/comp-sim.js`, 자동 학생 `node test/bots.js`
